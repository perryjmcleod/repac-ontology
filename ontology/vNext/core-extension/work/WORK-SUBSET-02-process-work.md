# WORK L1 Subset — Process Work

## Source
Defined in REPAC vNext. Work module in REPAC v1.0 is an unpopulated stub; no subset structure is available to migrate.

## Definition
Process Work is work understood as a repeatable sequence of tasks organized into a method, workflow, or procedure.

## Scope Boundary
This subset covers work analysed as a structured flow, where ordering, dependencies, and repeatability are salient features.

## Included
- A repeatable workflow composed of tasks
- A procedure or method used to produce consistent execution
- A process definition used to coordinate or standardize work

## Excluded
- Single discrete tasks examined as units (covered by **Task Work**)
- The produced result/effect as the primary focus (covered by **Outcome Work**)

## Notes
This is an L1 subset definition only. Process modelling constructs and decomposition are deferred to controlled explosion.
