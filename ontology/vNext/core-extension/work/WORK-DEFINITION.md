# WORK — Definition

## Definition

Work defines the execution of actions undertaken to produce outcomes, whether defined or emergent. Work performs action and may embody or respond to governance conditions but does not establish authority, control, or accountability structures.

## Clarification

Work concerns what is done. It includes both structured execution and emergent activity.

Work operates within conditions defined by governance but does not define those conditions.

## Boundary Statement

Work is distinct from Governance.

Work performs actions and produces outcomes.  
Governance defines decision rights, control, and accountability.

Work executes.  
Governance regulates.

## Critical Note

Work may contain embedded governance mechanisms, but those mechanisms remain governance constructs. Execution does not become governance through embedding.

## Prohibited Constructions

The following constructions are not valid within the REPAC ontology:

- work defines authority  
- process equals governance  
- execution is governance
