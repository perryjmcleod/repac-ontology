# WORK L1 — Candidate Subsets

## Objective
Identify the controlled Layer 1 candidate subsets for Work in REPAC vNext using a structurally valid ontological distinction.

## Candidate Work L1 Subsets

1. `WORK-SUBSET-01-defined`
2. `WORK-SUBSET-02-emergent`

## Rationale

The previous candidate set (`task`, `process`, `outcome`) was structurally invalid because it mixed different ontological levels:

- `task` described a unit of work
- `process` described an organized structure of work
- `outcome` described a result of work

This introduced category mixing between action, structure, and result.

The corrected candidate set classifies Work by how it exists relative to execution:

- **Defined Work** is specified prior to execution
- **Emergent Work** arises during execution and is not fully pre-specified

This distinction preserves ontological consistency and supports element-layer stabilization.

## Constraints

- No conceptual expansion
- No ontology drift
- No OWL/TTL population
- Maintain clean separation between Work, Value, and Purpose
