# WORK L1 Subset — Task Work

## Source
Defined in REPAC vNext. Work module in REPAC v1.0 is an unpopulated stub; no subset structure is available to migrate.

## Definition
Task Work is work understood as a discrete unit of execution performed to complete a specific action.

## Scope Boundary
This subset covers work analysed at the level of individual tasks or task-like units, independent of whether they occur inside a broader process.

## Included
- A single action with a clear completion condition
- A step that can be assigned, executed, and completed as a unit
- One-off work items that do not imply repeatability

## Excluded
- Repeatable sequences that define a workflow (covered by **Process Work**)
- The resulting product/effect as the primary focus (covered by **Outcome Work**)

## Notes
This is an L1 subset definition only. Task typing and decomposition are deferred to controlled explosion.
