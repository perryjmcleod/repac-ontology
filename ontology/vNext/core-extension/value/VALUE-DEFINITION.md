# VALUE — Definition

## Definition

Value defines the significance or worth attributed to something, either inherently or through its utility. It establishes what makes something matter, independent of the original intent behind it.

## Clarification

Value concerns importance, benefit, or meaning. It may exist regardless of whether it was intentionally pursued.

Value does not define why something was done.

## Boundary Statement

Value is distinct from Purpose.

Value defines what makes something matter.  
Purpose defines why something is pursued.

Value establishes significance.  
Purpose establishes intent.

## Critical Note

Value may emerge without intention, and intended outcomes may fail to produce value. These constructs must not be conflated.

## Prohibited Constructions

The following constructions are not valid within the REPAC ontology:

- value equals purpose  
- purpose is value  
- intrinsic purpose used to mean inherent value  
- assigned value used to mean declarative purpose
