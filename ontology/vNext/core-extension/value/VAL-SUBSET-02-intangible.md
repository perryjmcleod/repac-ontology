# VAL-SUBSET-02-intangible

## Label

Intangible

## Parent

Value

## Level

L1 Subset

## Definition

Intangible value captures value that is perceived, interpretive, relational, symbolic, cultural, reputational, experiential, or otherwise non-material in how it is realized or recognized.

## Boundary

This subset concerns value that is real analytically but not primarily expressed through direct material manifestation.

It does not by itself require immediate financial, physical, or operational measurability.

## Notes

This subset is analytically distinct from tangible value. Intangible value may influence tangible outcomes, but it should not be reduced to them.
