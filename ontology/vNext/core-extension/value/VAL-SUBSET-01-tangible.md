# VAL-SUBSET-01-tangible

## Label

Tangible

## Parent

Value

## Level

L1 Subset

## Definition

Tangible value captures value that is materially observable, measurable, countable, or otherwise concretely realized in physical, financial, operational, or directly evidentiary form.

## Boundary

This subset concerns value that can be identified through concrete manifestation or materially traceable outcome.

It does not by itself capture perceived, symbolic, relational, cultural, or experiential value that lacks direct material manifestation.

## Notes

This subset is analytically distinct from intangible value. Tangible value may coexist with intangible value, but the two should not be collapsed.
