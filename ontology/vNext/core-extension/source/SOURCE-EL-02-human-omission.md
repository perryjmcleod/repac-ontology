# SOURCE-EL-02 — Human Omission

## Element ID
`SOURCE-EL-02-human-omission`

## Label
Human Omission

## Subset
`SOURCE-SUBSET-01-human`

## Definition
A human non-action where an expected or possible action does not occur and enters the system as an absence.

## Description
Represents the absence of a human-performed action. This includes skipped steps, inaction, or failure to act, captured strictly as a missing input without assigning evaluation.

## Constraints
- Must represent absence of action
- Must not encode blame, error, or intent
