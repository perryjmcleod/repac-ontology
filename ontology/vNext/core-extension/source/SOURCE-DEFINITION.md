# SOURCE — Definition

## Definition

Source identifies the provenance or derivational basis of the material, signal, observation, or input used in analysis. Source governs what the analysis is grounded in, independent of how the analysis is framed.

## Clarification

Source concerns origin. It answers the question of where something comes from or what it is derived from. It does not determine how that material is examined.

## Boundary Statement

Source is distinct from Scope.

Source defines the origin or basis of analytical material.  
Scope defines the frame within which that material is examined.

A change in Source alters provenance.  
A change in Scope alters analytical framing.

## Critical Note

Source must not be used to express internal or external positioning. Those constructs belong to Scope as boundary or perspective lenses.

## Prohibited Constructions

The following constructions are not valid within the REPAC ontology:

- internal source or external source as Source classifications  
- source perspective  
- source boundary
