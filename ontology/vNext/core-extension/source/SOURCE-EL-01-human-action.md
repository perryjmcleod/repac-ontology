# SOURCE-EL-01 — Human Action

## Element ID
`SOURCE-EL-01-human-action`

## Label
Human Action

## Subset
`SOURCE-SUBSET-01-human`

## Definition
A human-performed action that enters the system of analysis as an observable behaviour.

## Description
Represents a discrete act carried out by a human actor. This includes physical movements, decisions executed, or interactions performed that contribute input into the system under analysis.

## Constraints
- Must be observable or inferable as an action taken
- Does not encode correctness, intent, or outcome
