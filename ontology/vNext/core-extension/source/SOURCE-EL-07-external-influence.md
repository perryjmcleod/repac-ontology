# SOURCE-EL-07 — External Influence

## Element ID
`SOURCE-EL-07-external-influence`

## Label
External Influence

## Subset
`SOURCE-SUBSET-04-environmental`

## Definition
An external environmental factor that interacts with or affects the system as an input.

## Description
Represents environmental or contextual forces that act upon the system. This includes disturbances, interference, external events, or dynamic conditions affecting system behaviour.

## Constraints
- Must originate outside the system boundary
- Does not encode impact severity or outcome
