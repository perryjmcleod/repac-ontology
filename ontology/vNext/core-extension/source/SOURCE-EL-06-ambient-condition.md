# SOURCE-EL-06 — Ambient Condition

## Element ID
`SOURCE-EL-06-ambient-condition`

## Label
Ambient Condition

## Subset
`SOURCE-SUBSET-04-environmental`

## Definition
A persistent environmental condition that enters the system of analysis as a background state.

## Description
Represents environmental factors that are continuously present and influence system behaviour. This includes temperature, lighting, humidity, or spatial conditions.

## Constraints
- Must be persistent or ambient in nature
- Does not encode desirability or suitability
