# SOURCE-EL-05 — Recorded Artifact

## Element ID
`SOURCE-EL-05-recorded-artifact`

## Label
Recorded Artifact

## Subset
`SOURCE-SUBSET-03-documentary`

## Definition
A documentary artifact that captures or records information entering the system of analysis.

## Description
Represents stored or documented representations of information. This includes reports, logs, records, data entries, or captured states that reflect information about the system or its operation.

## Constraints
- Must represent recorded or stored information
- Does not encode completeness or accuracy
