# SOURCE-EL-04 — Instructional Artifact

## Element ID
`SOURCE-EL-04-instructional-artifact`

## Label
Instructional Artifact

## Subset
`SOURCE-SUBSET-03-documentary`

## Definition
A documentary artifact that provides instruction or guidance entering the system of analysis.

## Description
Represents documents or symbolic representations that prescribe, guide, or direct action. This includes procedures, manuals, policies, labels, or instructions used to inform behaviour.

## Constraints
- Must provide directive or guiding information
- Does not encode accuracy or quality
