# SOURCE-L1-SUBSET—system

## Source
Migrated from REPAC v1.0 (`repac-source.owl`) and normalized for vNext L1 packaging.

## Definition
A System Source is a source whose authority, constraint, or directional influence originates in a technical system, application, platform, or automated process.

## Scope Boundary
This subset covers sources that function through **system behaviour** (rules, logic, configuration, automation, computation) rather than human judgment in the moment of influence.

## Included
- Business systems and applications enforcing rules or constraints
- Automated workflows, schedulers, bots, or decision engines
- Configuration-driven constraints (e.g., parameter limits, validation rules)

## Excluded
- Human judgments and approvals (covered by **Human Source**)
- Static policies, standards, contracts, or written mandates as the primary artefact (covered by **Documentary Source**)
- Physical environment constraints (covered by **Environmental Source**)

## Notes
This is an L1 subset definition only. Elements, system types, and modelling of rule structures are deferred to controlled explosion.
