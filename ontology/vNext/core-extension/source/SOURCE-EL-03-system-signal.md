# SOURCE-EL-03 — System Signal

## Element ID
`SOURCE-EL-03-system-signal`

## Label
System Signal

## Subset
`SOURCE-SUBSET-02-system`

## Definition
A system-emitted signal or output that enters the system of analysis as a machine-generated input.

## Description
Represents any observable output, state indication, or data emission produced by a system. This includes logs, alerts, readings, outputs, or state changes expressed by the system.

## Constraints
- Must originate from a system or automated process
- Does not encode correctness or failure
