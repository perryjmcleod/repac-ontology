# REPAC vNext  
## Phase: Controlled Superset Explosion  
### Target Superset: Scope  
### Layer: 1 (Structural Decomposition Only)

---

## 1. Objective

Decompose the **Scope Superset** into eligible Layer-1 Subsets under strict boundary discipline.

This phase is structural only.

No:
- Workflow modelling  
- Method prescription  
- Intervention guidance  
- Context reification  
- Analytical claims beyond structural eligibility  

---

## 2. Authoritative Alignment

This phase must align with:

- REPAC v1.0 Top Layer diagram  
- REPAC v1.0 TTL artifacts  
- Scope Pilot (Phase V-4B cross-check matrix)  
- Scope–Governance bridge artefacts  
- Boundary enforcement rules  

Layer-1 decomposition must preserve frozen v1.0 semantics.

---

## 3. Explosion Rule Set (Locked)

Layer-1 Subsets must:

1. Represent structurally distinct dimensions of delimitation.
2. Be necessary but not sufficient.
3. Avoid overlap with:
   - Purpose
   - Imperative
   - Work
   - Governance
4. Avoid modelling “context” as a first-class construct.
5. Avoid temporal sequencing.
6. Avoid operational prescription.

Any violating candidate is rejected.

---

## 4. Structural Question

Scope answers:

> “What is explicitly bounded for consideration in this analytical frame?”

Layer-1 subsets must represent non-redundant bounding dimensions.

Each candidate must pass:

- Cross-case applicability (minimum three cases)
- Non-prescriptive compliance
- Non-reification audit
- Cross-superset collision audit
- TTL formalizability test

Failure in any dimension results in rejection or revision.
