# SCOPE — Definition

## Definition

Scope defines the analytical frame within which examination occurs by specifying perspective, boundary, granularity, and interval. Scope governs how analysis is bounded, oriented, and resolved, independent of the origin of the material being examined.

## Clarification

In REPAC vNext, Scope regulates the conditions under which analysis is conducted. It determines what is included or excluded, from what vantage point something is examined, at what level of detail, and across what span.

## Boundary Statement

Scope is distinct from Source.

Scope defines how analysis is framed.  
Source defines what the analysis is grounded in.

A change in Scope alters the frame of examination.  
A change in Source alters the provenance of the material being examined.

## Critical Note

In REPAC vNext, internal and external are treated as Scope lenses rather than Source subsets because they regulate analytical framing rather than provenance.

## Prohibited Constructions

The following constructions are not valid within the REPAC ontology:

- internal source or external source as Source classifications  
- source perspective  
- source boundary
