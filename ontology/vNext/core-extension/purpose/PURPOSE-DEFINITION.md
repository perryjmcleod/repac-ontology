# PURPOSE — Definition

## Definition

Purpose defines the intended or declared reason for action, direction, or articulation. It establishes why something is pursued, independent of whether it is ultimately valuable.

## Clarification

Purpose governs intent. It may be inherent or declared, but it always represents a directional rationale for action or positioning.

Purpose does not guarantee that outcomes are valuable.

## Boundary Statement

Purpose is distinct from Value.

Purpose defines why something is pursued.  
Value defines what makes something matter.

Purpose establishes intent.  
Value establishes significance.

## Critical Note

Intent does not guarantee value, and value does not require originating intent. These constructs must remain analytically independent.

## Prohibited Constructions

The following constructions are not valid within the REPAC ontology:

- purpose equals value  
- value is the reason for action  
- intrinsic purpose used to mean inherent value  
- assigned value used to mean declarative purpose
