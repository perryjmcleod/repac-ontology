# PUR-SUBSET-02 — assigned

## Subset ID
`PUR-SUBSET-02-assigned`

## Label
Assigned

## Definition
A purpose that is designated or imposed by an external actor, system, or authority.

## Description
Represents purpose that is defined through external assignment rather than arising from the inherent nature of the entity or system.

Purpose defines why something exists. Assigned purpose reflects externally defined direction, expectation, or objective.

## Constraints
- Must originate from an external source (e.g., human, system, organization)
- Does not require alignment with intrinsic behavior
- Does not encode outcome, success, or effectiveness

## Usage Examples

- A project is defined to improve customer satisfaction
- A policy establishes an objective for compliance
- A system is configured to achieve a specified target
