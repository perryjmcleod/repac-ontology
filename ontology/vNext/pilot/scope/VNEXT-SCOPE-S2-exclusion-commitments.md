# VNEXT-SCOPE-S2 — Exclusion Commitments

ID: VNEXT-SCOPE-S2  
Parent Superset: Scope  
Label: Exclusion Commitments  
Short Definition (≤25 words): Boundary commitments declaring what is treated as excluded from analysis, as a stated condition of what the scope does not contain.  
Analytical Role: Stabilizes what is not counted in-scope, reducing ambiguity in interpretation and comparability.  
Inclusion Criteria: Statements or representations that specify exclusion as a boundary condition.  
Exclusion Criteria: Remediation actions; governance enforcement steps; prioritization; evaluation language.  
Relations:
  - depends_on: Scope
  - constrains: Work, Governance, Value (as boundary commitments)
  - overlaps_with:
Notes: Exclusion is not neglect; it is a stated boundary condition.
