# VNEXT-SCOPE-S1 — Inclusion Commitments

ID: VNEXT-SCOPE-S1  
Parent Superset: Scope  
Label: Inclusion Commitments  
Short Definition (≤25 words): Boundary commitments declaring what is treated as included within analysis, as a stated condition of what the scope contains.  
Analytical Role: Stabilizes what is counted as “in-scope” for interpretation and comparison.  
Inclusion Criteria: Statements or representations that specify inclusion as a boundary condition.  
Exclusion Criteria: Operational steps for managing scope; role assignments; quality judgements; prioritization rules.  
Relations:
  - depends_on: Scope
  - constrains: Work, Governance, Value (as boundary commitments)
  - overlaps_with:
Notes: Descriptive boundary declaration only. No sequencing or control implications.

## Elements

### VNEXT-SCOPE-E1 — In-Scope Set
ID: VNEXT-SCOPE-E1  
Parent Subset: VNEXT-SCOPE-S1  
Label: In-Scope Set  
Atomic Definition (≤20 words): The set of items explicitly treated as included within scope for analysis.  
Evidence Indicators: Scope statements; inclusion lists; boundary declarations.  
Analytical Boundary: Inclusion is descriptive; it does not justify or prioritize.
