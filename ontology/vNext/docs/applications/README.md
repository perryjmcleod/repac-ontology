# vNext Applications

This directory contains non-normative applications of REPAC vNext (worked cases, teaching views, practitioner notes). These artifacts demonstrate use. They do not define or modify REPAC semantics.

## Conventions

- Each application should state: purpose, audience, assumptions, and which REPAC artifacts it uses (v1.0 only, or v1.0 + vNext modules).
- Avoid prescriptive language. Describe analysis, not interventions.
