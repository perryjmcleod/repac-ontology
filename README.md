# REPAC Ontology

This repository contains the formal ontology, diagrams, and supporting artifacts
for the REPAC Framework — a structured analytical ontology for purpose-driven
analysis, decision-making, and value realization in complex organizational systems.

## Scope of This Repository

This repository includes:

- Conceptual diagrams defining REPAC Supersets, Subsets, Sets, and Elements
- Formal OWL / RDF / TTL representations of the ontology
- Supporting governance decisions and modeling constraints
- Materials supporting academic publication and pedagogy

This repository does not contain:
- Implementation-specific tooling
- Domain-specific extensions (these will be separate repos)
- Training courseware or marketing assets

## Status

Current version: **v1.0 (in progress)**  
Ontology structure is locked at the Superset and Subset level.  
Element-level expansion and formal encoding are ongoing.
