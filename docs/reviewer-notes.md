# Reviewer Notes and External Feedback Log

This document records anticipated and received reviewer feedback for
REPAC Ontology v1.0.

It exists to preserve review history and interpretive context.
It does not form part of the ontology and carries no normative authority.

## Purpose

The purpose of this file is to:
- Track recurring reviewer concerns
- Preserve rebuttal reasoning
- Avoid re-litigating resolved critiques
- Support future publication and presentation contexts

## Anticipated Reviewer Concerns (v1.0)

### 1. Analyst Judgment vs Ontological Constraint

Concern:
REPAC relies on analyst discipline rather than formal constraint.

Resolution:
Boundary enforcement rules prohibit substitution, primacy, and
intent-based classification. Invalid explanations are disallowed,
not discouraged.

Status:
Resolved for v1.0.

---

### 2. Narrative Convergence and Hidden Primacy

Concern:
The walkthrough converges on implicit causal hierarchy.

Resolution:
The walkthrough explicitly rejects causal primacy and states that
no single Superset is explanatory in isolation. Dependency is not
hierarchy.

Status:
Resolved for v1.0.

---

### 3. Value as Explanatory Sink

Concern:
Value is under-specified or absorbs explanation.

Resolution:
Value is explicitly defined as evaluative and non-causal.
Value absence prevents evaluation rather than explaining failure.

Status:
Resolved for v1.0.

---

### 4. Communication vs Collaboration Ambiguity

Concern:
These domains are difficult to separate in practice.

Resolution:
Adjudication rules distinguish shared interpretation (Communication)
from structurally enabled joint action (Collaboration).

Status:
Resolved for v1.0.

---

### 5. Mathematical Framing Rigor

Concern:
Combinatorial language is metaphorical.

Resolution:
REPAC explicitly disclaims numeric computation. Structural combinatorics
are used to describe state space, not calculate outcomes.

Status:
Resolved for v1.0.

---

### 6. Framework vs Ontology Classification

Concern:
REPAC resembles a framework rather than an ontology.

Resolution:
REPAC enforces analytically necessary domains, non-substitutability,
and invalid explanation prevention—hallmarks of applied ontology.

Status:
Resolved for v1.0.

---

## Residual Philosophical Disagreements

Some reviewers may object on the basis of:
- Preference for representational ontologies
- Desire for computational inference
- Expectation of prescriptive output
- Discomfort with restrictive analytical constraints

These are acknowledged as philosophical or disciplinary preferences
rather than technical deficiencies.
