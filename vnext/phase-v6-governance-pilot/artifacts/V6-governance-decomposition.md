# REPAC vNext — Phase V-6
## Governance Decomposition (Pilot)

This document decomposes Governance as an analytical domain for use in
Scope ↔ Governance cross-checking. It is non-prescriptive and records
structural distinctions only.

## A. Definition
Governance refers to decision rights, accountability structures, and
control mechanisms that constrain or enable action.

## B. Core Constructs
- Decision rights
- Accountability
- Controls and enforcement
- Exception handling
- Boundary authority

## C. Evidence Artifacts
- Policies and standards
- Approvals and delegations
- Audit trails
- Exception records
- Oversight reports

## D. Failure Modes
- Unauthorised decision-making
- Ambiguous or conflicting authority
- Control bypass or non-enforcement
- Post-hoc rationalisation
- Shadow governance

## E. Interfaces
- Scope (boundary authority and change control)
- Work (authorisation and execution limits)
- Value (accountability for outcomes)

## F. Import Audit
This section confirms that Governance decomposition is imported as a
reference input for cross-domain analysis.
