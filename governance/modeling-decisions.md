# REPAC Ontology – Modeling Decisions Log

This document records authoritative modeling decisions for the REPAC Ontology.
Once recorded here, decisions are considered locked unless explicitly revised.

## Locked Decisions

### 1. Context Handling
Context is not modeled as a first-class construct.
Context is treated as an interpretive lens applied externally.

### 2. Element Representation
REPAC Elements are modeled as OWL Classes, not Individuals.

### 3. Scope Classification
Internal Source and External Source are classified as Scope-related lenses,
not as Source Subsets.

### 4. File Generation Strategy
OWL / TTL files are generated only after semantic stabilization.
Diagrams and prose are considered the authoritative pre-formal source.
